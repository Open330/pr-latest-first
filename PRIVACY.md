# Privacy Policy

Last updated: May 22, 2026

PR Latest First is a Chrome extension that changes the reading order and entry
position of GitHub pull request Conversation pages in the user's browser.

## Data Handling

PR Latest First does not collect, transmit, sell, or share personal data,
browsing history, GitHub repository information, pull request content, comment
content, or analytics events.

The extension reads the rendered GitHub pull request Conversation page locally
in the browser only to:

- move loaded comment and review-comment entries into the selected reading mode;
- start at the bottom when that mode is selected; and
- show optional top and bottom jump controls.

This page reading is limited by the extension manifest to GitHub pull request
URLs and is not sent anywhere.

## Stored Settings

PR Latest First stores only extension preferences through Chrome extension
storage:

- the selected pull request Conversation mode; and
- whether jump controls are shown.

These settings are used only to apply the user's chosen extension behavior.

## Remote Code and Analytics

PR Latest First does not execute remote code and does not include analytics,
tracking pixels, advertising SDKs, or telemetry endpoints.

## Contact

Questions or privacy requests can be opened as an issue in the PR Latest First
GitHub repository.
